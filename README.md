# Insurance · The Storm Inbox

A 45–60 minute IBM Bob brownfield workshop. A storm in Bengaluru leaves MonsoonSure Insurance with twelve claims and two adjusters. Extend the existing claims register so a supervisor can decide which claim to dispatch next.

**Participants:** Start with the [exercise brief](starter/README.md). It contains the story, dispatch rules, acceptance checks and optional IBM Bob prompts.

**Facilitators:** Use the [session guide](facilitator/README.md) for timing and expected demo results.

From the repository root, run the following with Node.js 22 or newer. The starter uses Node’s standard library.

```sh
npm --prefix starter test
npm --prefix starter start
```

Open [the claims register](http://127.0.0.1:7991).
